# AI News Digest - 2026-10-02

## 1. Google「Gemini 4 Argon」発表 ── 出力100万トークン、18項目中12項目でGPT-6 Astra・Opus 5.5を上回る
**URL:** https://gihyo.jp/article/2026/10/gemini-4-argon

- Googleが9月30日に次世代最上位モデル「Gemini 4 Argon」を発表。コーディング・リサーチ・ライティングなど主要ベンチマーク18項目中12項目でGPT-6 AstraとClaude Opus 5.5を上回るスコアを記録。
- 出力トークン上限を業界最大の100万に拡大。ソフトウェアの脆弱性を自動で発見・検証・修正する能力を備え、サイバーディフェンス用途に特化した先行提供を開始。
- API価格は入力$2/出力$10（百万トークンあたり）。まずFairwindプログラムで信頼できるセキュリティ組織に限定提供し、一般開発者・企業向けは後日公開予定。

## 2. OpenAI DevDay 2026で常時稼働エージェント「Dots」発表 ── GPT-6 Astra搭載、4,000超アプリ連携
**URL:** https://forest.watch.impress.co.jp/docs/news/2144866.html

- OpenAIがDevDay 2026で常時稼働AIエージェント「Dots」を発表。ユーザーが自分専用のクラウドPC「dot」を作成でき、GPT-6 Astraを頭脳として24時間自律稼働する。
- 4,000以上のアプリと連携し、メール・カレンダー・ドキュメント作成などのタスクを自律的に実行。チーム向け共有ワークスペース「ChatGPT Space」も同時に発表。
- 月額500ドルの新プラン「ChatGPT Pro Ultra」を新設。GPT-6.1 SolはAstraの約1/5の価格で同等水準の性能を提供。

## 3. ChatGPTにバーチャル試着機能と書類スキャン→PDF化機能が追加
**URL:** https://www.itmedia.co.jp/news/article/2610/02/2000001945/

- OpenAIが10月1日、ChatGPTのPlus・Pro・Teamプランにバーチャル試着機能を追加。ユーザーが自分の写真をアップロードすると衣類やアクセサリーを仮想的に試着できる。
- 「お気に入り」機能も追加され、気に入った商品を保存して後から参照可能に。今年3月のショッピングリサーチ機能に続くEコマース領域の強化。
- さらにカメラで書類をスキャンしてPDF化する機能も同時リリース。ChatGPTを日常ツールとして幅広く活用する方向性を加速。

## 4. Microsoft、Copilotを大幅刷新 ── 「仕事のための新しいOS」へ再設計
**URL:** https://www.watch.impress.co.jp/docs/news/2143076.html

- Microsoftが9月25日にCopilotを大幅刷新。ナデラCEOが「仕事のための新しいOS」と宣言し、Home・Code・Autopilotの3機能を中心に再設計。
- 「Code」では自然言語でアプリ・ダッシュボード・自動化を構築可能。「Autopilot」はユーザーが名前・役割・目標を設定するデジタルチームメイトとして機能。
- Home・CodeはFrontierプログラムで数週間以内にロールアウト開始。10月にはスケジュール管理を支援する「Today」機能も追加予定。

## 5. Anthropic、Claude Sonnet 4.5の廃止を予告 ── 11月30日リタイア、移行先はSonnet 5.5
**URL:** https://aismiley.co.jp/ai_news/claude-code-update-summary-2026/

- Anthropicが9月30日、Claude Sonnet 4.5の廃止を予告。リタイア日は2026年11月30日で、移行先としてSonnet 5.5を案内。
- Sonnet 5.5はコスト効率と速度のバランスを重視したミドルティアモデルとして、速度が約30%向上し企業ユースケースでの実用性が高まっている。
- 既存のSonnet 4.5利用者は11月末までにAPI・プロンプトの移行が必要。Anthropicはモデルの世代交代を加速している。

## 6. Claude Code v2.1.286リリース ── VS Codeブックマーク、Slack支出上限などを追加
**URL:** https://dev.classmethod.jp/en/articles/20260707-cc-updates-v2-1-202/

- Claude Code v2.1.285でデスクトップアプリをカレントディレクトリで起動する`claude --desktop`コマンド、`claude plugin configure`コマンド、APIプロバイダーを制限する`allowedProviders`管理設定を追加。

- Claude Tag（Slack連携）にチャンネル別支出上限機能が追加され、組織でのAI利用コスト管理がより細かく可能に。
