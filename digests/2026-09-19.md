# AI News Digest - 2026-09-19

## 1. OpenAI、全個人向けプランでカスタムGPT（GPTs）の新規作成を停止 ── プラグインへ移行
**URL:** https://www.ai-jitan-hub.com/news/chatgpt-plugins-guide-2026

- OpenAIが9月19日、Free・Plus・Proを含む全個人向けプランで新規Custom GPTの作成とGPT Storeへの公開を停止。
- Enterpriseプランは9月25日に新規作成終了、12月11日に完全停止の予定で、「プラグイン」への移行を促進。
- ChatGPTの製品構成がChat・Work・Codexの3本柱に再編される中、カスタマイズの仕組みもプラグイン中心に刷新。

## 2. Apple、次世代Apple Intelligenceを提供開始 ── Siri AIの日本語対応は10月予定
**URL:** https://www.apple.com/jp/newsroom/2026/09/the-next-generation-of-apple-intelligence-is-available-today/

- Appleが9月14日、iOS 27とともに次世代Apple Intelligenceの機能提供を開始。英語版Siri AIのベータ版が利用可能に。
- Siri AIは「Apple Foundation Model」を基盤とし、オンデバイス処理とPrivate Cloud Computeを組み合わせたマルチモーダルAI。
- 日本語対応は10月予定。フランス語・韓国語・ポルトガル語・スペイン語も同時期に対応予定。

## 3. Google、Windows版Geminiアプリを世界提供開始 ── Alt+Spaceで即起動
**URL:** https://pc.watch.impress.co.jp/docs/news/2140107.html

- Googleが9月10日、Windows 10/11向けデスクトップアプリ「Gemini app for Windows」を全世界で提供開始。
- Alt+Spaceキーで作業画面に重ねて呼び出せ、作業の流れを中断せずにファクトチェックや資料作成が可能。
- パーソナルAIエージェント「Gemini Spark」との連携やGmail・Googleドライブからの情報引き出しにも対応。

## 4. Claude Code v2.1.276リリース ── Projects機能ベータ提供開始、97件の変更を含む大型更新
**URL:** https://dev.classmethod.jp/articles/20260918-cc-updates-v2-1-276/

- 9月17〜18日にClaude Code v2.1.275〜v2.1.276がリリース。新機能13件・改善21件・修正62件の計97エントリを含む大型アップデート。

- v2.1.276ではプロキシ経由利用時に全リクエストが400エラーになるリグレッションを緊急修正。

## 5. ChatGPT Work「Data Agent」発表 ── SQLなしで社内データ基盤に直接接続・分析
**URL:** https://uravation.com/media/chatgpt-work-data-agent-2026-09/

- OpenAIが9月10日、ChatGPT Workの新機能「Data Agent」を発表。Redshift・BigQuery・Snowflake・Databricksなど7種以上に対応。
- SQLを書かずに自然言語で質問するだけで、原因調査から対話型ダッシュボード作成・共有まで1つの会話で完結。
- 非エンジニアでもデータドリブンな意思決定が可能になり、エンタープライズ向けデータ分析のハードルを大幅に低下。

## 6. Anthropic CEO Dario Amodei「We Must Pace the Frontier」── AI開発速度への警鐘
**URL:** https://ai2roi.substack.com/p/ai-to-roi-news-and-analysis-september-789

- Anthropic CEOのDario Amodeiが9月12日、フロンティアAIの開発速度が人類の評価・制御・安全確保の能力を上回りつつあると警鐘を鳴らすエッセイを公開。
- 再帰的自己改善の初期兆候や暴走する自律エージェントなどの高深刻度リスクの存在を指摘。

## 7. GPT-6 Astra ロールアウト継続中 ── コンピュータ操作機能搭載の次世代フラッグシップ
**URL:** https://openai.com/index/gpt-6-astra/

- OpenAIが9月3日に発表したGPT-6 Astraのロールアウトが継続中。テキサスStargate拠点で10万GPU以上を用いた史上最大規模の学習。
- コンテキスト長105万トークン、最大出力12.8万トークン。画面認識によるOS操作・ファイル編集・ブラウザ操作を自律遂行する「computer use」機能を搭載。
- ChatGPT Plus・Pro・Business・Enterprise、OpenAI API、AWSへの段階的展開が進行中。
